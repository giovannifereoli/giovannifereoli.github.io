This is the Python code from my M.S. thesis, developed at Prof. Hanspeter Schaub's Autonomous Vehicle Systems (AVS) Lab. It trains an LSTM-based meta-reinforcement-learning agent with Proximal Policy Optimization, using [Stable-Baselines3](https://stable-baselines3.readthedocs.io/), to guide a spacecraft during proximity operations in the Circular Restricted Three-Body Problem.

The package is released under the [MIT](https://choosealicense.com/licenses/mit/) license. Questions, issues, and suggestions are welcome.
