**GUBAS-RS** is an open-source Rust software project developed by Giovanni Fereoli and published on GitHub.

The project is part of my scientific/engineering software work and is designed to provide a performant and reliable Rust-based implementation that can be used in research and technical workflows.

### What is GUBAS-RS?

GUBAS-RS is a Rust package focused on:

- **performance**, using Rust for efficient numerical and systems-level execution,
- **reliability**, with strong typing and memory safety guarantees,
- **open development**, so users can inspect, reproduce, and extend the implementation.

This repository is intended both as a usable software component and as a foundation for future extensions in astrodynamics/scientific tooling.
